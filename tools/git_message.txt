Polish1 D3c: darts against other players online for chips (item 71)

Another player as the opponent: the board opens for a challenger (game and stake), someone else at that throw line is offered Join and pays the same stake. The host keeps the match (game/net_darts.gd): a throw sends only the aimed point, the host adds the spread, scores it and sends the landing and the new state to everyone; the players' machines fly the dart and follow the score, everyone else sees the darts on the board. The host names the winner, also when the other player leaves; the winner gets twice the stake, a cancelled open board refunds it. Pair set dartsnet: the guest joined the host's 501 for 50, the host won on D20 (+50, guest -50), and the guest leaving a second game gave it to the host.
