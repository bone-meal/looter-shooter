Round 5 batch 3: three save slots per build version

Start Game and Multiplayer go through a save menu: three slots, each one
whole character; an empty slot asks for a name and the first session opens
the customize menu. Saves live in user://saves/<version>/ (version from
data/build.json, written by the release tool; "dev" from the editor), so a
new version starts with three empty slots and older saves stay untouched.
The player card starts with the character's name instead of "Unnamed".
