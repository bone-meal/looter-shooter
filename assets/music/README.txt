SONGS FOR THE HIDDEN SECRETS AND THE CLUB'S JUKEBOX (data/zombies/songs.json)

Put up to ten music files here, named   Artist - Title.mp3   (.ogg and .wav work too).
The game sorts them by file name: the first file is the song of hidden secret 1, the second of secret 2, and so on.
It shows the part before " - " as the artist and the rest as the title.
Open the project in the Godot editor once after adding files (it imports them), then they go into the game and
into every release.
